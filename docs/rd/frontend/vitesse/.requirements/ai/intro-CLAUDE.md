# CLAUDE.md 文件分析

## 文件概述

`CLAUDE.md` 是项目的核心指令文件，为 Claude AI 提供项目的完整上下文和开发规范。它是 Claude Code 工具识别项目特性的主要入口。

## 文件内容结构

### 1. 项目概述

定义了项目的基础信息：
- 基于 Vitesse 模板构建
- 目标是扩展开发多种功能模块
- 强调响应式设计（PC 端和移动端）

### 2. 技术栈

详细列出了项目使用的所有技术和文档链接：
- Vue 3、Vue Router v5、Pinia、Vue I18n
- UnoCSS、Vite、vite-ssg
- VueUse、TypeScript、Vitest、Cypress

### 3. 项目结构

描述了 `src/` 目录的组织方式：
- `components/` - 通用组件（自动注册）
- `composables/` - 组合式函数（自动导入）
- `layouts/` - 布局组件
- `pages/` - 页面路由（文件系统路由）
- `stores/` - Pinia 状态管理
- `styles/` - 全局样式

### 4. 开发规范

涵盖六个主要方面：
1. **组件开发**：命名规范（The*、Base*、[Module]*）
2. **页面开发**：文件系统路由规则
3. **样式规范**：UnoCSS 优先，响应式断点
4. **状态管理**：Pinia Composition API 风格
5. **国际化**：YAML 格式语言包
6. **响应式设计**：移动优先原则

### 5. 常用命令

提供了完整的命令列表：
- `pnpm dev` - 开发服务器
- `pnpm build` - 构建
- `pnpm lint` - 代码检查
- `pnpm test` - 测试

### 6. 扩展模块规划

详细规划了五个功能模块：
- 图片浏览模块
- 阅读模块
- 百科模块
- 表格模块
- 图表模块

## 文件作用

### 1. 上下文传递

为 Claude AI 提供项目背景，使其能够：
- 理解项目目标和技术栈
- 遵循既定的开发规范
- 生成符合项目风格的代码

### 2. 规范指导

作为开发规范的权威来源：
- 定义命名约定
- 规定代码风格
- 指导架构决策

### 3. 功能规划

记录项目的功能扩展计划：
- 提供模块设计蓝图
- 指导未来开发方向
- 确保 AI 助手与项目目标一致

### 4. 自动化支持

支持 Claude Code 的自动化功能：
- 自动导入和注册机制说明
- 文件系统路由规则
- 构建和测试命令

## 最佳实践

1. **保持更新**：随着项目发展更新文件内容
2. **清晰明确**：使用简洁的语言描述规范
3. **结构化**：使用表格和代码块提高可读性
4. **链接文档**：提供相关技术的文档链接
5. **示例丰富**：包含代码示例说明规范应用
